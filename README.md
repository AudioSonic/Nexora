# Nexora

Nexora ist eine persönliche Lernplattform, die dabei unterstützt, neue Skills strukturiert und nachvollziehbar zu erlernen. Lerninhalte werden in Skills, Phasen, Themen und Übungen gegliedert; der Fortschritt wird aus den hinterlegten Daten berechnet.

Die Anwendung ist ein React-/TypeScript-Frontend auf Basis von Vite.

## Entwicklung

Abhängigkeiten installieren:

```bash
npm install
```

Entwicklungsserver starten:

```bash
npm run dev
```

Produktions-Build erstellen und prüfen:

```bash
npm run build
```

Linting ausführen:

```bash
npm run lint
```

## Projektstruktur

- `src/` enthält die React-Anwendung, Komponenten, Daten und Styles.
- `public/` enthält statische Dateien.
- `index.html`, `vite.config.ts` und die TypeScript-Konfiguration liegen im Projektstamm.
