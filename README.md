# Nexora  
<img width="1894" height="926" alt="grafik" src="https://github.com/user-attachments/assets/3558f2f4-5d53-470f-899d-44eb44abe924" />  

Nexora ist eine persönliche Lernplattform, die dabei unterstützt, neue Skills strukturiert und nachvollziehbar zu erlernen. Lerninhalte werden in Skills, Phasen, Themen und Übungen gegliedert und können Schritt für Schritt abgeschlossen werden. Fortschritte, abgeschlossene Themen und Phasen werden automatisch aus den hinterlegten Daten berechnet. Das Projekt wird kontinuierlich erweitert und soll langfristig von einer zunächst statischen JavaScript-Anwendung zu einer vollständigen Webanwendung mit ASP.NET Core Backend, REST API und Datenbank ausgebaut werden. Der aktuelle Frontend-Prototyp wurde mit HTML5, CSS3 und JavaScript entwickelt und legt den Grundstein für die später hinzukommende Backend- und API-Architektur.

## Highlights
- Hierarchische Strukturierung von Skills, Phasen, Themen und Übungen,
- Dynamische Generierung der Benutzeroberfläche aus strukturierten Daten,
- Automatische Berechnung von Themen-, Phasen- und Skill-Fortschritten,
- Fortschrittsanzeige für einzelne Skills und den gesamten Lernstand,
- Schrittweise Freischaltung von Phasen abhängig vom Lernfortschritt,
- Automatische Freischaltung des Abschlussprojekts nach Abschluss aller Themen,
- Responsive Benutzeroberfläche für Desktop und mobile Geräte,
- Kontinuierlich erweiterbares Konzept mit geplanter ASP.NET-Core-REST-API und Datenbank
